# 👖 Jeans Manufacturing Company Ltd. (JMCL)
### Official Website & Admin CMS Portal

A full-stack, responsive, and SEO-optimized web application for **Jeans Manufacturing Company Ltd. (JMCL)**, built with Node.js, Express, SQLite, and vanilla modern JavaScript.

---

## 🚀 How to Run Locally (লোকাল পিসিতে চালানোর নিয়ম)

### অপশন ১: কমান্ড লাইনের মাধ্যমে
```bash
npm install
npm start
```

### অপশন ২: এক ক্লিকে (Windows)
* ফোল্ডারে থাকা **`run_server.bat`** ফাইলে ডাবল-ক্লিক করুন।

সার্ভার চালু হলে ব্রাউজারে নিচের লিঙ্কে প্রবেশ করুন:
* 🌐 **মূল ওয়েবসাইট:** [http://localhost:3000/#p-home](http://localhost:3000/#p-home)
* 🔒 **অ্যাডমিন প্যানেল:** [http://localhost:3000/admin](http://localhost:3000/admin)

## 🌟 Key Features (ওয়েবসাইটের প্রধান সুবিধাসমূহ)
1. **ডাইনামিক অ্যাডমিন সিএমএস:** ওয়েবসাইট কোড এডিট না করেই অ্যাডমিন প্যানেল থেকে লোগো, ফ্যাভিকন, প্রোডাক্ট, জব সার্কুলার, ক্লায়েন্ট লোগো, ডিরেক্টরদের প্রোফাইল ইত্যাদি পরিবর্তন বা এডিট করা যায়।
2. **রেসপনসিভ ডিজাইন:** মোবাইল, ট্যাবলেট, ল্যাপটপ ও বড় ডেস্কটপ মনিটরে নিখুঁতভাবে প্রদর্শিত হয়।
3. **হাই-লেভেল সিকিউরিটি:** রেট লিমিটিং, ফাইল আপলোড এক্সটেনশন ভ্যালিডেশন, ইনপুট স্যানিটাইজেশন ও সিকিউর রেসপন্স হেডার যুক্ত।
4. **ফ্রি লাইভ হোস্টিং রেডি:** Render, Railway বা যেকোনো ক্লাউড হোস্টিংয়ে সরাসরি ডিপ্লয় করার উপযোগী।
